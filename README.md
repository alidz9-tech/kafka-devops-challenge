# Kafka DevOps Challenge 🚀

A robust, secure, and automated Kafka cluster setup.

## 📋 Available Commands

|Command|Description|
|---|---|
|setup-certs|Generates CA and certs.|
|create-topic|Creates a new Kafka topic.|
|healthcheck|Checks status of containers.|
|test|Runs end-to-end test.|
|failover|Simulates broker failure.|
